## 👨‍💻 About Me

I'm a student at **[1337 (42 Network)](https://1337.ma/)**, UM6P Rabat. I like low-level programming, algorithms and Linux. I'd rather rebuild a tool from scratch than just call it, because that's how I learn how it works.

- 🔭 **Working on:** the 42 Common Core, with a focus on algorithms and memory management
- 🌱 **Learning:** data structures, Unix system programming, and graphics programming in C
- 👯 **Open to:** collaborating on C and 42 projects
- 💬 **Ask me about:** C, Linux, shell scripting, Git, algorithms
- ⚡ **Fun fact:** I debug with `printf()` and I'm not ashamed of it 🐛
